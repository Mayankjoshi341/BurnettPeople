
# BurnettPeople API Contract

Status: Day 1 draft — pending Dev A / Dev B agreement

## General conventions

- API prefix: `/api/`
- Request and response bodies: JSON
- Field naming: snake_case
- Authentication: JWT Bearer access token for protected APIs
- Dates: `YYYY-MM-DD`
- Timestamps: ISO 8601 with timezone information
- Attendance timestamps are generated by the backend.
- PostgreSQL is the source of truth for HR records.

## Health

GET `/api/health/`

Authentication: Public

Success response:

{
  "status": "ok",
  "checks": {
    "database": "ok",
    "redis": "ok"
  }
}

A failed dependency returns HTTP 503.

## Proposed endpoint groups

- Authentication: `/api/auth/`
- Employees: `/api/employees/`
- Work schedules: `/api/work-schedules/`
- Attendance: `/api/attendance/`
- Breaks: `/api/breaks/`
- Leave requests: `/api/leave-requests/`
- Tea expenses: `/api/tea-consumption/`

Exact routes, payloads, response codes, and validation-error
formats must be agreed upon before frontend feature work.

## Authorization rules

- Employee: submit and view their own leave requests.
- Manager: review assigned leave requests and add comments.
- HR: make final leave approval or rejection decisions.
- Role-based authorization must be enforced by the backend.

## Attendance rules

- Five-minute grace applies to late-arrival calculation.
- Normal checkout requires the scheduled work duration,
  calculated from the actual check-in time.
- Attendance checkout does not automatically invalidate JWTs.
- Exact grace-period boundary behavior remains pending confirmation.

## Break rules

- Record timestamps on the server.
- The entire break must fit within its permitted window.
- Calculate compliance on the backend.
- Violations require an explanation and must be available for HR review.

## Open decisions

- Exact 10:05 AM lateness boundary.
- Early checkout exceptions.
- Minimum attendance duration for arrivals within the grace period.
- Fixed versus maximum break duration.
- JWT access-token lifetime and refresh-token policy.
